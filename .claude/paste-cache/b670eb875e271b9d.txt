 # 2.5D 跑酷角色精灵表动画 — 骨骼参数提示词

  ## 技术约束

  渲染目标：80×100 像素离屏 Canvas
  视角：3/4 背视图（从背后略上方俯视）
  绘制方式：基于角度参数的骨骼肢体绘制（非逐像素精灵）

  ## 骨骼参数系统

  角色由以下参数化部件组成：
  - **躯干**：梯形连帽衫，绕髋部旋转（lean 参数）
  - **头部**：椭圆 + 头发 + 护目镜带（headTurn: 'back'|'left'|'hurt'）
  - **双腿**：每腿 hipA（大腿角）+ kneeA（膝角），末端画鞋
  - **双臂**：每臂 shldA（上臂角）+ elbowA（肘角），末端画圆形手
  - **阴影**：底部椭圆

  ### 角度坐标系

  所有角度以弧度为单位，0 = 垂直向下：

  | 参数 | 正方向 | 含义 |
  |------|--------|------|
  | `hipA` | + = 向前摆 | 大腿相对垂直线的角度 |
  | `kneeA` | + = 弯曲 | 小腿相对大腿的角度（0=伸直） |
  | `shldA` | + = 向前摆 | 上臂相对垂直线的角度 |
  | `elbowA` | + = 弯曲 | 前臂相对上臂的角度（0=伸直） |
  | `lean` | + = 前倾 | 躯干绕髋部前倾（rad） |
  | `bounce` | + = 上升 | 全身垂直偏移（px，正值=身体上移） |

  ### 关键角度参考值

  | 身体部位 | 自然下垂 | 微摆 | 大幅摆动 | 极限 |
  |---------|---------|------|---------|------|
  | 大腿前摆 | 0 | ±0.2~0.4 | ±0.5~0.7 | ±0.8 |
  | 大腿侧展 | 0 | — | ±0.10~0.20 | — |
  | 膝盖弯曲 | 0~0.1 | 0.3~0.5 | 0.6~0.9 | 1.1（深蹲） |
  | 上臂前摆 | 0 | ±0.2~0.4 | ±0.5~0.8 | ±0.9（上举） |
  | 肘部弯曲 | 0~0.1 | 0.2~0.4 | 0.5~0.7 | 0.8（抱臂） |
  | 躯干前倾 | 0.05~0.10 | 0.12~0.18 | 0.25~0.35 | 0.45（滑铲） |

  ### 解剖锚点

  hipY = 52 + bounce    // 髋部 Y 坐标（52=站立位）
  shldY = hipY - 28     // 肩部 Y（躯干长 28px）
  headY = shldY - 16    // 头顶 Y
  shldW = 16            // 肩宽
  hipW = 9              // 髋宽
  手臂长 = 13 + 11      // 上臂 13px + 前臂 11px
  腿长 = 16 + 14        // 大腿 16px + 小腿 14px

  ## 动画设计原则（12 法则应用）

  1. **预备动作**：任何大动作前先反向压缩（跳前下蹲、铲前收身）
  2. **跟随动作**：落地后身体继续下沉 1-2 帧再回弹
  3. **挤压拉伸**：bounce 负值=压缩，正值=拉伸
  4. **弧形运动**：四肢角度变化应有缓入缓出，不线性
  5. **次要动作**：手臂摆动幅度比腿大 20-30% 增加动感
  6. **节奏**：接触帧（着地）时间短（1-2 帧），过渡帧时间长（4-6 帧）

  ## 跑步循环（8 帧，~7.5 fps）

  跑步循环 = 接触 → 下沉 → 经过 → 蹬起 → 接触(另一脚)

  每个阶段的设计要点：

  ### 接触帧（Frame 0, 4）
  - 前脚刚触地，后脚即将离地
  - 前腿 hipA: +0.35~0.40, kneeA: 0~0.05（近乎伸直）
  - 后腿 hipA: -0.50~-0.55, kneeA: 0.35~0.40（蹬地后弯曲）
  - 手臂与腿反向：前腿侧手臂后摆，后腿侧手臂前摆
  - bounce: -1~-2（轻微下压）
  - lean: 0.07（微前倾）

  ### 下沉帧（Frame 1, 5）—— 最重要的重量感帧
  - 支撑腿弯曲吸收冲击，身体降到最低点
  - 支撑腿 kneeA: 0.45~0.65（深弯），hipA: 0.15~0.20
  - 摆动腿 kneeA: 0.55~0.65（折叠收紧），hipA: -0.20~-0.25
  - 手臂摆动幅度最大化：前摆手 shldA: +0.40，后摆手 shldA: -0.60
  - bounce: -3~-4（最低点）
  - lean: 0.06

  ### 经过帧（Frame 2, 6）
  - 摆动腿经过支撑腿，身体开始上升
  - 摆动腿 kneeA: 0.70（最大折叠），hipA: ±0.10
  - 支撑腿开始蹬伸：kneeA 减小到 0.15
  - 手臂经过身体中线：shldA: ±0.05, elbowA: 0.50
  - bounce: 0（中立位）
  - lean: 0.08

  ### 蹬起帧（Frame 3, 7）
  - 后腿蹬离地面，身体达到最高
  - 蹬地腿 hipA: -0.50, kneeA: 0.25（向后蹬直）
  - 前摆腿 hipA: +0.40, kneeA: 0.55（高抬）
  - 手臂摆到极限：shldA 达到 ±0.30
  - bounce: +2~+3（弹起）
  - lean: 0.09

  ## 跳跃（4 阶段，总长 150 帧）

  ### 阶段 1：预蹲蓄力（前 15 帧）
  **目标**：身体压缩到最低，传达「即将爆发」的信息
  - bounce: -10~-12（大幅下压）
  - lean: 0.15（微前倾，保持重心）
  - 双腿：hipA 略微展开 ±0.15，kneeA: 0.85~0.95（深蹲）
  - 双臂：shldA: +0.45~+0.55，elbowA: 0.55~0.65（手臂后摆蓄力）
  - 关键：这个帧必须看起来「被压缩的弹簧」

  ### 阶段 2：腾空上升（135→76 帧）
  **目标**：身体充分伸展，传达「向上爆发」
  - bounce: +8~+12（明显上移）
  - lean: 0.08~0.12（微前倾，不后仰）
  - 双腿：一腿前踢 hipA: +0.30, kneeA: 0.30；一腿后蹬 hipA: -0.38, kneeA: 0.30
  - 双臂：shldA: -0.80 和 +0.75（一臂向上，一臂略低，不对称才自然）
  - 加分：motionLines: true（速度线）
  - 关键：双腿不能完全并拢（并拢像僵尸跳），应该一前一后分开

  ### 阶段 3：下落（75→34 帧）
  **目标**：重力感，身体从伸展过渡到准备落地
  - bounce: +2~+5（仍略高于中立位）
  - lean: -0.02~0.0（近乎垂直，略后仰模拟空气阻力）
  - 双腿：微收准备落地，hipA: ±0.15~0.22, kneeA: 0.25~0.35
  - 双臂：shldA: -0.25 和 +0.30，elbowA: 0.35~0.40（手臂微微张开保持平衡）
  - 关键：不能和阶段 2 一样伸展，要明显收拢

  ### 阶段 4：落地缓冲（33→0 帧）
  **目标**：重冲击感，传达「重量落地」
  - bounce: -8~-10（压缩吸收冲击）
  - lean: 0.12~0.15（微前倾稳定）
  - 双腿：kneeA: 0.68~0.75（膝盖深弯缓冲），hipA: ±0.15~0.20
  - 双臂：shldA: +0.35~+0.45，elbowA: 0.50~0.55（手臂前伸保持平衡）
  - 落地瞬间应触发尘土粒子效果
  - 关键：这个帧和阶段 1「预蹲」很像，但手臂更前伸（预蹲时手臂后摆）

  ## 滑铲（3 阶段，总长 100 帧）

  ### 阶段 1：进入滑铲（100→71 帧）
  **目标**：从跑姿降入滑铲，传达「主动下潜」
  - bounce: -10~-14（明显下移）
  - lean: 0.28~0.35（明显前倾，不是后仰！）
  - 前腿：hipA: +0.50~+0.60, kneeA: 0.05~0.12（前伸，几乎伸直）
  - 后腿：hipA: -0.05~-0.10, kneeA: 0.80~0.90（折叠在身下）
  - 双臂：一臂前伸 shldA: +0.45~+0.50，一臂后拉 shldA: +0.10~+0.15, elbowA: 0.45
  - 关键：滑铲的 lean 必须是正的（前倾），后仰的滑铲 100% 不像滑铲

  ### 阶段 2：贴地滑行（70→31 帧）
  **目标**：最低姿态，传达「贴地高速滑行」
  - bounce: -16~-20（极低，贴近地面）
  - lean: 0.38~0.45（强烈前倾）
  - 双腿：都在前方，前腿 hipA: +0.70~+0.75 kneeA: 0~0.05；后腿 hipA: +0.10, kneeA: 0.80
  - 双臂：展开保持平衡，shldA: -0.10 和 +0.52, elbowA: 0.30~0.55
  - 加分：motionLines: true
  - 关键：这是最低点，身体越贴近地面越有速度感

  ### 阶段 3：起身恢复（30→0 帧）
  **目标**：从滑行恢复到跑姿，传达「重新站起」
  - bounce: -6~-9（开始上升但仍偏低）
  - lean: 0.15~0.20（前倾减小）
  - 双腿：收腿准备站立，hipA: 0.25~0.35, kneeA: 0.50~0.65
  - 双臂：收拢配合起身，shldA: 0.10~0.35, elbowA: 0.50~0.55
  - 关键：起身高度应介于滑行最低点和站立之间

  ## 常见错误检查清单

  写每个 pose 后对照：

  - [ ] 滑铲的 lean 是正值（前倾）吗？（之前错设为 -0.50 后仰）
  - [ ] 跳跃的腾空帧双腿分开了吗？（并拢 = 僵尸跳）
  - [ ] 预蹲和落地的手臂方向不同吗？（预蹲=后摆蓄力，落地=前伸平衡）
  - [ ] 手臂和腿是反向摆动吗？（同手同脚 = 机器人走路）
  - [ ] 每个阶段的 bounce 有明显变化吗？（都一样 = 弹簧人）
  - [ ] 膝盖弯曲角度有变化吗？（始终弯 = 蹲着跑；始终直 = 棍子人）
  - [ ] 躯干 lean 有变化吗？（始终同角度 = 木板人）

  ## 输出格式

  每个 pose 用以下 JSON 描述：

  ```json
  {
    "bounce": 0, "lean": 0.08, "headTurn": "back",
    "lLeg": { "hipA": 0, "kneeA": 0 },
    "rLeg": { "hipA": 0, "kneeA": 0 },
    "lArm": { "shldA": 0, "elbowA": 0 },
    "rArm": { "shldA": 0, "elbowA": 0 },
    "motionLines": false
  }
