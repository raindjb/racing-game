## DeepSeek 替代方案

CrewAI 支持通过 `crewai.LLM` 配置任何 OpenAI 兼容 API：

```python
from crewai import LLM

# DeepSeek 替代
llm = LLM(
    model="openai/deepseek-chat",  # 或 "openai/deepseek-reasoner"
    base_url="https://api.deepseek.com/v1",
    api_key="sk-...",
)

# 或通过环境变量
# .env:
# OPENAI_API_KEY=sk-...
# OPENAI_API_BASE=https://api.deepseek.com/v1
# MODEL=openai/deepseek-chat
```

所有使用 OpenAI 的示例都可以通过这种方式切换到 DeepSeek。

## 装好后直接跑的路径

### 最快路径：scaffold + 跑模板

```bash
# 1. 安装 CrewAI
uv pip install crewai

# 2. 生成 Crew 项目
crewai create crew my_first_crew --skip_provider
cd my_first_crew

# 3. 配置 DeepSeek
echo 'OPENAI_API_KEY=sk-your-deepseek-key' > .env
echo 'OPENAI_API_BASE=https://api.deepseek.com/v1' >> .env
echo 'MODEL=openai/deepseek-chat' >> .env

# 4. 安装依赖
crewai install

# 5. 跑
crewai run
```

### 最快路径：scaffold Flow 项目

```bash
# 1. 生成 Flow 项目
crewai create flow my_first_flow --skip_provider
cd my_first_flow

# 2. 同上配置 DeepSeek .env

# 3. 安装依赖
crewai install

# 4. 跑
crewai run
```

### 外部示例路径

```bash
# 1. clone 示例仓库
git clone https://github.com/crewAIInc/crewAI-examples.git
cd crewAI-examples/crews/trip_planner

# 2. 配置 .env

# 3. crewai install && crewai run
```

## 推荐首选运行：`crewai create crew my_first_crew --skip_provider`

**理由：**
1. **零额外 clone** — 模板已在本地仓库内，不需要联网下载
2. **依赖最少** — 只需 `crewai` 一个包，不需要 `crewai-tools`、`SerperDevTool` 等
3. **可直接用 DeepSeek** — 模板没有硬编码任何 base_url，通过 .env 配置即可
4. **演示效果最直观** — researcher 搜索 + analyst 写报告，两步完成，输出 `report.md`
5. **30 秒出结果** — 从 `crewai create` 到看到输出，不超过 1 分钟
