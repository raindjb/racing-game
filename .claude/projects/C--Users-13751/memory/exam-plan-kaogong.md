### 公考P2策略

- **主攻**: 资料分析（67%→75%）→ 方法优化 + 速算 + 每天限时
- **日课**: 数量关系 15题/天（稳定正确率，缩小波动）
- **维持**: 言语+判断各1套/周
- **碎片**: 半月谈App，每天10-15min常识时政积累
- **申论**: 6月每周1篇（轻量），7月起每周2篇+批改

## 双赛道

### Track 1: 证券从业（6月，4周速通）
- 科目: 金融市场基础知识 + 证券市场基本法律法规
- 及格线: 60分/科
- 报名: sac.net.cn
- 资源: 官方教材×2、233网校/钉题库App、三色笔记

- 目标: 国考 + 京考
- 阶段: P1诊断(已跳过) → P2靶向突破 → P3模考 → P4冲刺
- 资源: 粉笔App（免费版）、半月谈/人民日报App、B站免费课（齐麟/花生十三/刘文超）

## 公考每日结构（6月，1.5-2h）

- **必做**: 资料分析 15题限时 + 数量关系 15题限时（共~1h）
- **维持**: 言语或判断 1套（每周各1次，~30min）
- **碎片**: 半月谈常识时政（10-15min）
- **申论**: 每周1篇（周末做，轻量）

## 证券每日结构（6月，1-1.5h）

- 第1周: 教材通读 + 章后习题
- 第2-3周: App章节练习 + 错题归集
- 第4周: 模考冲刺 + 错题二刷
