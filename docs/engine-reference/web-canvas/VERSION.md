## Note

The Canvas 2D API has been stable for over a decade. The core API (`drawImage`, `fillRect`, `arc`, transforms, compositing) is unchanged. No breaking changes are expected.

Key browser APIs used (all stable and well-documented):
- Canvas 2D Context API
- `requestAnimationFrame`
- Web Audio API (AudioContext, OfflineAudioContext, AudioBuffer)
- Touch Events API
- `localStorage`
